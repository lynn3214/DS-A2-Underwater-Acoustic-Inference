# Processed Daily Analysis Data

`daily_analysis.csv` is regenerated by `python src/run_phase1.py` from the immutable NOAA hourly CSV after SHA-256 validation. UTC start-of-bin records are converted to `America/New_York`; daily windows and inclusion rules are defined in `config/experiment_protocol.yaml`. No missing-value interpolation or undocumented QC exclusion is used.

Columns:

- `local_date`: local calendar date assigned to the day and night pair.
- `day_valid_hours`, `night_valid_hours`: finite source indicator count in each 8-bin window.
- `day_mean_db`, `night_mean_db`: arithmetic means of published hourly dB indicators, present even when a date does not meet eligibility if at least one window value exists.
- `daily_difference_db`: night mean minus day mean; present only for dates meeting the primary >=6/8 rule in both windows.
- `eligible_6_of_8`: primary inclusion flag.
- `eligible_8_of_8`: full-coverage sensitivity flag.

This is derived research data, not an original NOAA file. Provenance/checksum linkage is in `results/audit/provenance.json` and `results/raw/phase1_run_manifest.json`.
