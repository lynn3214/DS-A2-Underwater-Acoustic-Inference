# Machine-Readable Phase 1 Results

All numerical outputs are regenerated by `python src/run_phase1.py` under `nussem1`; the run manifest pins the source checksum, protocol commit, environment, and seed root.

- `real_data_inference.json`: observed-data descriptive statistics and t, HAC, and MBB estimates/intervals.
- `daily_difference_acf.csv`: ACF by lag, pair count, and descriptive reference band.
- `sampling_distribution_summary.csv`: theoretical/empirical moments, Monte Carlo uncertainty, rejection rates, and seed by condition.
- `sampling_distribution_draws.csv`: each simulated sample mean, condition, and replicate number.
- `iid_power.csv`: analytical noncentral-t power, Monte Carlo rejection, Wilson interval, scenario, and seed for every plotted point.
- `ar1_stationarity_checks.json`: theoretical/empirical mean, variance, and lag-one diagnostics with seed.
- `ar1_counterexample_replicates.csv`: per-series/per-method interval decisions and widths; records include generating and bootstrap seeds.
- `ar1_counterexample_summary.csv`: grouped rejection/coverage rates with Wilson intervals and mean/median widths.

Simulation outputs are conditional method-validation experiments, not additional observations from NOAA.
