## Phase 0.5 metadata resolution and coverage

The direct SB02_13 `time.comment` and `time_stamp.comment` attributes in the official netCDF say “Start time of 1 hour bin over which sound pressure levels are calculated.” This is **direct, product-specific evidence** and is the basis for the high-confidence start-label interpretation. The user-specified IANA zone `America/New_York` was used. The series runs from 2020-11-22 through 2021-01-26; it contains no DST transition, and every record converts at UTC−05:00. Synthetic tests separately cover both DST boundaries.

There are 66 local dates in the source timestamp span. The first boundary date has 5 day-window and 8 night-window hours; the last boundary date has 3 day-window and 0 night-window hours. Each fails both paired-date rules. Among represented hourly bins, there are no missing or invalid values by local date or local hour. These are coverage findings only.

### Resolution findings and remaining limits

- **Timestamp semantics — resolved, high confidence:** the exact SB02_13 netCDF attribute directly identifies bin start times. Two related NOAA ERDDAP products give similar start-time comments, but those are recorded as indirect corroboration only. The direct SB02_13 ERDDAP `.das` request returned HTTP 403 because the request IP is on that server’s blacklist; this does not negate the netCDF evidence.
- **Time zone and DST — operationally resolved for this audit:** `America/New_York` was explicitly specified by the user and is consistent with the NOAA site coordinates. No DST transition falls within these observations. UTC-to-local conversions use aware datetimes and IANA `zoneinfo` rules.
- **Frequency band — unresolved metadata conflict:** the exact SB02_13 netCDF abstract/history, NCEI processing description, and `BB_10-24000` field name say 10–24,000 Hz. The exact product’s brief metadata JSON `DATA_QUALITY` entry says 20–24,000 Hz. This is not resolved by evidence from another product; request NOAA correction or clarification before treating the band as unambiguous.
- **Reuse terms — resolved for redistribution with stated terms:** the exact SB02_13 netCDF global `license` attribute says the data may be used and redistributed for free and provides a no-warranty/legal-use disclaimer. This is not a named Creative Commons or OSI license. The small processed CSV, netCDF and metadata snapshots are retained in Git; no raw audio is included.
- **QC — limitation remains:** the source has no row-level QC column or quantitative exclusion rule. The file has 1,560 finite values and the metadata describes the quality as good/visually assessed, but this does not substitute for row-level QC.

No one-hour shift sensitivity calculation was needed: the primary timestamp interpretation is supported directly by the product-specific attribute at high confidence. No day–night differences, effect estimates, intervals, tests, or power values were calculated.

## Verified source facts

- NOAA NCEI identifies DOI `10.25921/yyt5-g930` as broadband SPL at 1-hour resolution for SanctSound SB02_13, Stellwagen Bank; the observation period is 2020-11-22 through 2021-01-26. The NCEI record gives the precise extent as 2020-11-22 17:20 UTC to 2021-01-26 17:00 UTC.
- The NCEI processing description says 10–24,000 Hz, hourly values are the median of at least 1,800 one-second values, and units are dB re 1 µPa. The CSV column name is `BB_10-24000`.
- The companion brief JSON has a conflicting quality entry, `Frequency (Hz): 20 to 24000`. This discrepancy needs resolution before measurement compatibility is treated as fully verified.
- CSV timestamps carry a `Z` suffix and are whole-hour UTC labels. The metadata describes one-hour resolution but does not say whether a label denotes interval start, end, or center. The local time zone is not named in the dataset metadata.
- NOAA/NCEI documents visual/acoustic quality assessment, but the CSV has no QC column and metadata gives no row-level quality flag or quantitative exclusion rule. Metadata provides liability and citation constraints, but no explicit open license or redistribution grant was found.

Sources: [NCEI dataset landing page](https://www.ncei.noaa.gov/access/metadata/landing-page/bin/iso?id=gov.noaa.ncei.pad:NOAA-Navy-SanctSound_SB02_13_BB_1h), [official NOAA public bucket listing](https://storage.googleapis.com/noaa-passive-bioacoustic/?prefix=sanctsound/products/sound_level_metrics/sb02/sanctsound_sb02_13_bb_1h/).
